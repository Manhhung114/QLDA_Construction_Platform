# QLDA Construction Platform

Nền tảng quản lý dự án xây dựng mới, triển khai độc lập với hệ thống QLDA hiện tại.

Mục tiêu V1: 12 module lõi gồm Project & Portfolio, Task & WBS, Schedule, Resource, BOQ & Cost, Contract & Procurement, Document Control, Quality, Change Management, Collaboration, Dashboard & BI, Automation & AI.
